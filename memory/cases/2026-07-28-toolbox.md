# 2026-07-28: P2S/X2D no-logo toolbox preflight

This records an exact profile inspection and workflow decision; no completed
print outcome was captured.

## Source

- Model/profile: [P2S/X2D Toolbox, profile 2950059](https://makerworld.com/en/models/1895209-p2s-x2d-toolbox#profileId-2950059)
- Download inspected at the time: `x2toolbox_v2.3mf`
- License: not captured; verify the live listing before storing any model file
- Repository decision: provenance only; no downloaded model/profile is stored

## Verified 3MF state

Inspection of `Metadata/project_settings.config` and
`Metadata/model_settings.config` found:

- `enable_support = 0`
- `support_filament = 0`
- `support_interface_filament = 0`
- All three encoded filaments were PLA; none was marked as support material
- Selected plate: Textured PEI

Useful plates were:

- `Inserts`: approximately 170 g, mapped to white PLA
- `Case (No Logo)`: approximately 155 g, mapped to black PLA
- `Latches`: approximately 4 g, safely mapped to white PLA for this job

The logo-case plates were not part of the intended print.

## Preflight result

Supports and dedicated support filament were unnecessary. Each intended plate
was effectively single-color, so Bambu Handy with ordinary filament mapping was
the simplest reliable workflow. The case should cool fully on the Textured PEI
plate before removal.

## Reusable guidance

- Inspect the exact profile and intended plates rather than reasoning from the
  model page or thumbnails alone.
- When page metadata cannot establish support state, inspect the authenticated
  3MF configuration.
- Do not use Studio merely because a 3MF exists; use it when the recipe needs
  inspection beyond the preflight or an actual change.
