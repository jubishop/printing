# 2026-07-28: X2D/P2S poop-bin preflight

This records a profile inspection and workflow decision; no completed print
outcome was captured.

## Source

- Model/profile: [X2D, P2S Poop Bin, profile 2964185](https://makerworld.com/en/models/2677120-x2d-p2s-poop-bin#profileId-2964185)
- Profile title at the time: `0.2mm layer, 2 walls, 15% infill`
- Observed profile estimate: approximately 3 hours and 158 g
- License: not captured; verify the live listing before storing any model file
- Repository decision: provenance only; no downloaded model/profile is stored

## Preflight result

The exact X2D-compatible profile was support-free, so dedicated support
filament was unnecessary. Its default material was PLA Basic, while PETG was a
normal supported material substitution for the intended print.

The appropriate workflow was Bambu Handy: select the X2D profile, map the model
to PETG, verify the material and plate, and print without a support filament.
Bambu Studio added no value unless Jubi wanted to alter the profile or inspect
and tune the slice.

An attempted Studio inspection did not reach a verified configured or sliced
state. It must not be cited as evidence that a Studio setup was completed.

## Reusable guidance

- Do not assume a support spool is needed because one is available.
- Handy can map a normal supported material substitution.
- If a profile is support-free and otherwise suitable, prefer Handy over Studio.
- Verify UI state after consequential app actions and distinguish a planned
  configuration from one that was directly observed.
